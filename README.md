# VDetekt

<!-- Plugin description -->
This plugin will help make sure you don't introduce security vulnerabilities into
your source code whether knowingly or unknowingly, by flagging them as you implement. 

It checks  for common vulnerabilities in Android source codes such as SQL injection vulnerability, 
Insecure data storage, Insecure data communication etc.
<!-- Plugin description end -->

## Installation

- From JetBrains Plugin Repository:
  
  Search for VDetekt and install.
  
- Manually:

  Download the [zip file]() and go to Android studio, 
- --> Android Studio --> Settings --> Plugins --> ⚙️ --> Install plugin from Disk
- select the downloaded zip file and install. Restart IDE. Enjoy!.
